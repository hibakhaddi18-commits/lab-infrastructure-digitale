! Topologie : S1, S2, S3 en triangle, chaque paire reliee par un
!             bundle EtherChannel (LACP, mode actif, ports en trunk)
! Bundles (exemple) :
!   S1 : Po1 vers S2, Po2 vers S3
!   S2 : Po1 vers S1, Po2 vers S3
!   S3 : Po1 vers S1, Po2 vers S2
! Interfaces visibles sur la capture : S1 Gig0/2 et Fa0/22,
!   S2 Gig0/2 et Fa0/24, S3 Fa0/22 et Fa0/24.
! Chaque bundle regroupe 2 liens physiques : ajoute le 2e lien
! physique de chaque bundle dans le meme channel-group
! (a verifier dans ta maquette).
!
! ==================== S1 ====================
enable
configure terminal
hostname S1
no ip domain-lookup
!
! Bundle vers S2
interface GigabitEthernet0/2
 description Bundle vers S2 (membre Po1)
 channel-group 1 mode active
 no shutdown
! (Ajouter ici le 2e lien physique vers S2 : channel-group 1 mode active)
!
interface Port-channel1
 description EtherChannel vers S2
 switchport mode trunk
 switchport trunk allowed vlan all
 no shutdown
!
! Bundle vers S3
interface FastEthernet0/22
 description Bundle vers S3 (membre Po2)
 channel-group 2 mode active
 no shutdown
! (Ajouter ici le 2e lien physique vers S3 : channel-group 2 mode active)
!

 description EtherChannel vers S3

end
